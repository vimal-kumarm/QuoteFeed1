# ⚡ QuoteFeed — JS fetch() API Project

A live data fetching web app built with **HTML, CSS & JavaScript** — Day 6 Project of my Python Full Stack Developer journey.

---

## 🚀 Live Demo
> Open `index.html` in your browser — no installation needed!

---

## ✨ Features

- 💬 Fetch **random quotes** from Quotable API
- 😂 Fetch **random jokes** from Joke API
- 🐶 Fetch **dog facts** from DogAPI
- 🐱 Fetch **cat facts** from CatFact API
- 📜 **Fetch history** — last 10 fetched items saved in localStorage
- 📋 **Copy** any result to clipboard
- 🌀 Loading spinner while fetching
- ⚠️ Error handling with user-friendly messages
- 💾 History persists after page refresh (localStorage)

|---------|-----------|
